PORTFÓLIO MAX VERSTAPPEN — HTML, CSS E JAVASCRIPT

ARQUIVOS
- index.html: estrutura e conteúdo da página
- style.css: cores, layout, responsividade e animações
- script.js: menu mobile, barra de progresso e animações de entrada

COMO ABRIR NO VS CODE
1. Extraia o arquivo ZIP.
2. Abra a pasta "portfolio_max_verstappen" no Visual Studio Code.
3. Abra o arquivo index.html.
4. Para uma experiência melhor, use a extensão "Live Server" no VS Code e clique em "Go Live".
   Também é possível abrir index.html diretamente no navegador.

OBSERVAÇÕES
- O site usa fontes do Google Fonts e fotos ilustrativas externas, então a internet é necessária para carregá-las.
- As imagens não são fotografias oficiais de Max Verstappen. Troque as URLs no index.html e no style.css caso queira inserir fotos autorizadas.
- Conteúdo informativo e não oficial. Estatísticas podem mudar com o tempo.
- Fontes de referência: perfil oficial da Fórmula 1 (formula1.com) e perfil da Red Bull (redbull.com).

- max-verstappen-trofeu.jpg: foto enviada pelo usuário e incorporada ao portfólio.
